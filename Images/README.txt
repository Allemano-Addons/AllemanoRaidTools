Pictures for Visual note backgrounds.

1. Make one from a screenshot: right-click Tools\img2tga.ps1 > Run with PowerShell, or
   powershell -ExecutionPolicy Bypass -File Tools\img2tga.ps1 -Src C:\path\shot.png -Name ony_p2
   It writes Images\ony_p2.tga (1024x512).
2. RESTART WoW (a /reload does not find new files).
3. Visual note > Picture > type ony_p2 and press Enter.

Everyone who should see the picture needs the same file in their Images folder
(share it on Discord). The visual note itself only sends the name.
