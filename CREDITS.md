# Credits

**Allemano Raid Tools** is part of Allemano Addons (https://allemano.org).

## How it is made

Designed, directed and tested by Allemano. Much of the code is written with AI assistance (Claude, by Anthropic) under that direction. Releases are tested in the game before they are published, and the changelog says what changed.

## Third-party code

Allemano Raid Tools contains no third-party code or libraries. It uses the World of Warcraft API and, where installed, the public interfaces of other addons; nothing from them is bundled.
